# Instructions for agents

This repository keeps its instructions for every agent in [CLAUDE.md](CLAUDE.md), whichever agent
you are. Read it before you change anything, and follow it as if it were this file.

- Each package has its own instructions too: `packages/<package>/CLAUDE.md`. Read the one for a
  package before you change it.
- CLAUDE.md names skills, such as `milestone` and `regression-check`. Each is a file,
  `.claude/skills/<name>/SKILL.md`. Read it before you do the work it covers.
- What holds now in an area: `docs/area/<area>.md`. CLAUDE.md says when to read and change it.
