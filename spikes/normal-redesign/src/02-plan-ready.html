Save a cart for later

Today

A cart lives only in memory (src/cart/cart.ts): it is lost when the page closes. Accounts and sessions exist, but nothing stores a cart.

What I’d change

  1. src/cart/saved.ts (new): saveCart(accountId, cart) and loadCart(accountId), the lines and the code as JSON, one cart an account.
  2. src/api/carts.ts (new): PUT /carts/:account saves, GET loads; both 401 without a session.
  3. src/ui/CartView.tsx: a Save for later button, shown when signed in.
  4. Tests: a saved cart loads the same; a product removed since is dropped, with a note.

Unless you say otherwise

  • One saved cart an account; saving again replaces it.
  • Prices are not stored: a loaded cart is priced again from the catalog.
